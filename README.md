# Türk Masalları

## Proje Hakkında
Bu proje, Anadolu ve Türk coğrafyasından seçilen 8 geleneksel masalı bir araya getiren interaktif bir web sayfasıdır. Kullanıcılar, masal kartlarına tıklayarak seçtikleri masalları okuyabilir.

## Projenin Amacı
Türk kültürüne ait geleneksel masalları sade, anlaşılır ve kullanıcı dostu bir arayüz ile dijital ortama taşımak.

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript

## Dosya Yapısı
- `index.html`: Web sayfasının HTML yapısını içerir.
- `style.css`: Sayfanın tasarım ve biçimlendirme kodlarını içerir.
- `script.js`: Masalların açılması ve kapatılması gibi etkileşimleri sağlar.

## Projenin Çalıştırılması
Projeyi çalıştırmak için `index.html` dosyası bir web tarayıcısında açılmalıdır. CSS ve JavaScript dosyaları HTML dosyasına harici olarak bağlanmıştır.
